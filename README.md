# Bchat

一个基于蓝牙 / 局域网的**免服务器**即时通讯 + 文件传输 Android 应用。不依赖任何云端，两台（或多台）设备在局域网内即可互相发现、私聊、建群、传输文件和语音消息。

## 功能特性

- **设备发现**：在同一 WiFi 下自动发现局域网设备；也可通过蓝牙扫描发现
- **私聊**：蓝牙 / 局域网点对点连接，文字、文件、图片、语音消息
- **群聊**：星型拓扑（主机转发），支持建群 / 发现并加入群 / 入群昵称 / 可选入群密码
- **好友列表**：连接过的设备自动保存为好友，并在线 / 离线状态徽标
- **文件传输**：文件、图片、语音跨设备互传，FileProvider 安全访问
- **主题与个性化**：日间 / 夜间主题（跟随系统 / 浅色 / 深色）、磨砂玻璃效果、设置页个性化与连接排查日志

> 技术命名说明：Java 包名沿用 `com.codeflow`（历史命名），但产品品牌 / 应用名统一为 **Bchat**。

## 连接方式

### 私聊（蓝牙 / 局域网）
1. 两台设备安装 Bchat，处于同一 WiFi 网络（局域网）或开启蓝牙
2. 默认进入局域网页，点击「空白处刷新」发现设备
3. 点击列表中的设备发起连接，对方接受后进入聊天页

### 群聊
- **发现后加入**：好友页 / 搜索页会列出广播中的群，点击直接加入
- **手动加入**：好友页 →「加入群聊」，填写你的昵称，地址格式为 `房主IP地址:53319`（如 `192.168.1.5:53319`），如有密码则一并填写

## 端口说明

| 用途 | 端口 | 组播地址 |
|------|------|----------|
| 局域网设备发现 | 53317 | 224.0.0.167 |
| 局域网私聊传输 | 53318 | — |
| 群服务 | 53319 | — |
| 群发现 / 广播 | 53320 | 224.0.0.168 |

> 局域网发现 / 广播依赖组播（Multicast）与 `255.255.255.255` 广播，请确保路由器未开启 AP 隔离（AP Isolation），否则设备间无法互相发现。

## 环境与构建

- 语言 / 框架：Kotlin + Android
- 构建：Gradle Kotlin DSL
- 最低支持 Android 版本：见 `app/build.gradle.kts`

```bash
./gradlew :app:assembleDebug --offline
```

调试产物位于 `app/build/outputs/apk/debug/app-debug.apk`。
